# Беклог идей

Основной список — **[backlog.yaml](backlog.yaml)**: тема, тезис, первоисточники, оценки, причина выбора, статус и путь к выпуску.

```sh
npm run storygro -- ideas content/ideas/backlog.yaml
```

`candidate` — кандидат; `selected` — выбран для работы; `produced` — материал собран. Последний статус не означает публикацию в соцсеть. Инструменты сбора трендов и их конфигурация находятся отдельно: [production/trends](../../production/trends/README.md). Ролики — в [content/videos](../videos/README.md), проверки источников — в [content/research](../research/).
