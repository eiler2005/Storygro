9. Альфредо Ди Стефано

Название видео: «Пять Кубков чемпионов подряд!»

Краткий пересказ: Альфредо Ди Стефано был одним из главных игроков мадридского «Реала», который выиграл первые пять розыгрышей Кубка европейских чемпионов подряд — с 1956 по 1960 год. Ди Стефано забивал в каждом из пяти финалов.

Посекундный план:

| Время | Содержание |
| --- | --- |
| 0–2 | Пять золотых кубков появляются один за другим. Надпись: «ПЯТЬ ПОДРЯД?!» |
| 2–5 | Матвей: «Они выиграли пять раз подряд?!» |
| 5–9 | Появляется Альфредо Ди Стефано в форме «Реала». София: «Да! И одним из главных героев был Альфредо Ди Стефано!» |
| 9–16 | Пять кубков выстраиваются в ряд, Ди Стефано забивает гол. София: «С 1956 по 1960 год “Реал” пять раз подряд выигрывал Кубок европейских чемпионов. А Ди Стефано забивал в каждом финале!» |
| 16–21 | Матвей пытается поставить пять мячей в ряд. |
| 21–25 | София: «Вот это настоящая футбольная легенда!» |
