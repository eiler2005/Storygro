# Ролики

Каждая папка — отдельный контентный проект с собственными источниками, сценарием и assets. Производственные инструменты находятся в [production/](../../production/README.md).

| [football-now-01-messi-ronaldo](football-now-01-messi-ronaldo/README.md) | Современный спецвыпуск: долголетие, дисциплина и видение игры; футболисты в центре, настоящие фото, ведущие рядом; 98,7 с, для просмотра |

Что в какой папке и как одобряется — [контент-процесс](../../docs/explanation/content-workflow.md); статус всех выпусков — [TRACKER.md](../TRACKER.md). Серии (рубрики) описаны в [content/series/](../series/), профиль бренда — в [content/brand.yaml](../brand.yaml). Статус серии: `npm run storygro -- series content/series/business-explainers.yaml`.

Генерируемые MP4 и другие результаты лежат в локальных `.reel/`, публичные пакеты — в GitHub Releases. [Идеи](../ideas/README.md) ведутся отдельно. Сцена коллажа отрабатывалась на [внутреннем примере](../../examples/editorial-collage/README.md); его тема не является текущим заказанным выпуском.
