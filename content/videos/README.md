# Ролики

Каждая папка — отдельный контентный проект с собственными источниками, сценарием и assets. Производственные инструменты находятся в [production/](../../production/README.md).

| Проект | Назначение |
|---|---|
| [who-gets-rich-on-ai](who-gets-rich-on-ai/README.md) | «Кто разбогатеет на ИИ»: железнодорожная паника 1873 года как урок для ИИ-стройки; взрослый explainer по посту владельца, две версии (ru 135,2 с · en 134,2 с) на общих кадрах GPT Image |
| [football-stars-kids](football-stars-kids/README.md) | Детский мультик «Звёзды футбола: собираем альбом»: 14 футболистов, узнаваемые шаржи (GPT Image), главы и альбом; серия [kids-football](../series/kids-football.yaml); 117,5 с |
| [ballon-dor-kids](ballon-dor-kids/README.md) | Детский мультик «Золотой мяч: кто самый лучший?»; 89 с |
| [agent-motion-studio](agent-motion-studio/README.md) | Пилот стиля kinetic-type «Как агент собирает ролик из кода»; 31 с |
| [agents-open-door](agents-open-door/README.md) | Мультфильм-погоня «Не бунт, а открытая дверь» о безопасности ИИ-агентов; первый выпуск серии [«Открытая дверь»](../series/open-door.md) и первый по контент-процессу (план, вопросы, одобрения); 82 с |
| [ai-agent-checks](ai-agent-checks/README.md) | Где проверять работу ИИ-агента. Первая тема, выбранная по [сканированию трендов](../research/ai-agent-checks/README.md); 51,6 с |
| [slidecraft-demo](slidecraft-demo/README.md) | Демо продукта на настоящей записи экрана (`capture` → `screencast`); 43,7 с |
| [micro1-work-data](micro1-work-data/README.md) | Ролик по присланному посту: зачем покупают операционные данные для обучения агентов; 94,2 с |
| [future-of-work](future-of-work/README.md) | Деловой explainer о проверке и ответственности; 68,6 с |

Что в какой папке и как одобряется — [контент-процесс](../../docs/explanation/content-workflow.md); статус всех выпусков — [TRACKER.md](../TRACKER.md). Серии (рубрики) описаны в [content/series/](../series/), профиль бренда — в [content/brand.yaml](../brand.yaml). Статус серии: `npm run storygro -- series content/series/business-explainers.yaml`.

Генерируемые MP4 и другие результаты лежат в локальных `.reel/`, публичные пакеты — в GitHub Releases. [Идеи](../ideas/README.md) ведутся отдельно. Сцена коллажа отрабатывалась на [внутреннем примере](../../examples/editorial-collage/README.md); его тема не является текущим заказанным выпуском.
