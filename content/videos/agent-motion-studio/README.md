# Как агент собирает ролик из кода

Пилот стиля [`kinetic-type`](../../../production/styles/kinetic-type/README.md), вертикальный, около 31 секунды, серия [product-demos](../../series/product-demos.yaml). Это демо нашего инструмента, а не независимый обзор.

**Мысль одной строкой:** ролик можно не монтировать, а написать: сценарий и факты — данные, голос задаёт ритм, браузер рисует каждый кадр как функцию времени, а проверка ловит ошибки до выпуска.

| Файл | Что |
|---|---|
| [PLAN.ru.md](PLAN.ru.md) | план для просмотра (генерируется `storygro plan`) |
| [review.yaml](review.yaml) | вопросы к владельцу, заметки и одобрения |
| [ru.reel.yaml](ru.reel.yaml) | сценарий |
| [facts.json](facts.json), [sources.md](sources.md) | числа и источники |
| [CREDITS.md](CREDITS.md) | шрифты, голос, музыка |

## Сюжет

| Сцена | Говорит | Показывает |
|---|---|---|
| hook (`kinetic`) | видео — это код; каждый кадр — функция времени | слова падают в момент, когда звучат; акцентная полоса под «функция времени» |
| how (`process`) | сценарий → голос → кадры → проверка | изометрический путь из четырёх станций, «кадр» едет от станции к станции |
| evidence (`scale`) | в открытом каталоге 703 промпта, 418 повторены заново | два круга, площади пропорциональны числам, камера отъезжает |
| takeaway (`kinetic`) | ролик не монтируют, а программируют — и проверяют, как программу | «монтируют» сменяется на «программируют», тонкое → жирное |
| close (`kinetic`) | так собран и этот ролик; Storygro на GitHub | «Storygro» падает крупно |
