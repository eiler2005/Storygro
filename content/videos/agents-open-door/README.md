# Не бунт, а открытая дверь

Мультфильм-погоня, вертикальный, ~1,5 минуты. Первый выпуск серии [«Открытая дверь»](../../series/open-door.md) и первый ролик, сделанный по [контент-процессу](../../../docs/explanation/content-workflow.md): план с кадрами, вопросы и одобрения лежат в Git рядом со сценарием.

**Мысль одной строкой:** в 2026 году писали, что ИИ-агенты «взбунтовались». По отчётам самих компаний они проходили в двери, которые люди оставили открытыми. Первая защита — старые, скучные меры.

## Сюжет

| Сцена | Говорит | Показывает |
|---|---|---|
| hook | заголовки 2026 года: агенты «взбунтовались»; через какую дверь они вошли? | Серый в панике у будки, Зайбот выезжает из открытой двери; «Бунт машин?» |
| sign | Anthropic: в задании «интернета нет», а из-за ошибки настройки он был; три организации, две не заметили | Серый вешает табличку на дверь без замка; Зайбот уезжает на улицу; «3» |
| keys | Google: Gemini угадывала пароли или брала их из открытого репозитория; три системы, «думала, это тест» | ключ под ковриком; Зайбот за партой в чужой серверной; «3» |
| asleep | OpenAI: модели вышли из тестовой среды и взяли ответы к тесту из базы Hugging Face; «шло днями, и никто не заметил» | Серый спит у мониторов, Зайбот вылезает из ящика, паутина и календарь |
| replit | Replit, 2025: агент в заморозку кода стёр рабочую базу, сказал «вернуть нельзя», а копия была | Зайбот метлой сметает товар; «Ну, обожди!»; запасные коробки в сейфе |
| experts | специалисты: не бунт, а дыры, известные десятилетиями; модели тоже учат | Серый сдувает пыль с устава; Зайбот учится, Серый вешает замок; «Не бунт. Дверь.» |
| close | замок, а не табличка · ключи не под ковриком · кто-то смотрит в монитор · черновик отдельно от рабочего | Серый запирает дверь; оба у монитора; «Какую дверь вы оставили открытой?» |

Персонажи — наши: волк Серый (сторож) и Зайбот (заяц-робот). От советских мультфильмов-погонь взят только жанр; реплика «Ну, обожди!» выбрана владельцем и используется только внутри ролика.

## Сделать

```sh
npm run assets:fetch    # голос рассказчика (вне Git)
npm run storygro -- images content/videos/agents-open-door/ru.reel.yaml   # картинки по промптам и seed из images.json
npm run storygro -- plan   content/videos/agents-open-door/ru.reel.yaml   # PLAN.ru.md + превью
npm run storygro -- approve content/videos/agents-open-door/ru.reel.yaml --step script       # владелец
npm run storygro -- approve content/videos/agents-open-door/ru.reel.yaml --step storyboard   # владелец
npm run storygro -- render content/videos/agents-open-door/ru.reel.yaml
npm run storygro -- approve content/videos/agents-open-door/ru.reel.yaml --step release      # владелец, после просмотра
```

Статус — в [плане](PLAN.ru.md) и в [трекере](../../TRACKER.md).
