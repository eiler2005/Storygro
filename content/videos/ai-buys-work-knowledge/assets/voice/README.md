# English narrator

The same synthetic English narrator as the English cut of [AI and jobs](../../../../../examples/ai-jobs/README.md): a male reference designed for Storygro with Qwen3-TTS VoiceDesign and cloned per line with `qwen3`. Not a real person's voice. Its words are in [narrator-en.txt](narrator-en.txt); measurements in [voices](../../../../../docs/reference/voices.md).

The WAV stays outside Git; `npm run assets:fetch` restores it from [content/media-assets.json](../../../../media-assets.json) (311084 bytes, SHA-256 `33cb6a60b9c1263e5b05a35a9d48c723f4e3cc8ae12f9a0658f316d2fa26ac5e`).
