# Золотой мяч: кто самый лучший?

Короткий мультик для детей 6–10 лет, вертикальный, около 85 секунд. Что такое «Золотой мяч», кто его придумал, кто выбирает победителя и у кого больше всех наград. Ведёт сам мяч — Златик, рядом юная футболистка Маша.

**Мысль одной строкой:** «Золотой мяч» вручают лучшему футболисту года с 1956 года. Рекорд у Месси (8), единственный вратарь-победитель — Лев Яшин, а с 2018 года есть и женская награда. Получить его может каждый, кто любит игру.
