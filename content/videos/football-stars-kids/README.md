# Звёзды футбола: собираем альбом

Мультик для детей 6–10 лет, вертикальный, около двух минут: 14 футболистов из списка владельца и по одному весёлому проверенному факту о каждом. Подача — альбом наклеек: точки слева показывают, сколько звёзд уже собрано, а три главы делят футболистов на атаку, середину поля и вратарей. Ведут Златик и Маша из [«Золотого мяча»](../ballon-dor-kids/README.md).

## Pictures

24.10.2026 владелец попросил картинки «больше похожими на рисунки, сложнее, и чтобы дети узнавали персонажей» (первый вариант с обезличенными фигурками — Олисе «вообще не похож»). Сравнение на трёх одинаковых промптах с новой арт-дирекцией (рисунок тушью, цветные карандаши, акварель, детальный фон): локальная Z-Image-Turbo — простые фигурки, лица не узнаются, на форме вратаря появились эмблема и полоски бренда вопреки запрету; GPT Image (Codex CLI, gpt-6-astra) — узнаваемые шаржи (Роналдиньо, Куртуа), насыщенные фоны, те же Златик и Маша, без логотипов. Выбран GPT Image: провайдер `codex` в `storygro images`. Минусы: нужен вход в Codex, онлайн, ~40 с на картинку, нет воспроизводимого seed.

Видео и картинки вне Git (`.reel/`, `shots/`); картинки восстанавливаются командой `storygro images` по `images.json`. Ударения имён — из общего словаря `production/voices/lexicon-ru.yaml`.
