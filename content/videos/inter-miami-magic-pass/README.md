# Интер Майами: финальный пас

Вертикальный футбольный комикс для 10–12 лет. Маша учится создавать гол с командой; шесть карточек знакомят с действующими игроками «Интер Майами». Реальные факты отделены от вымышленного приключения.

Собранная версия: 114,48 секунды, 1080×1920, 30 кадров/с, H.264/AAC. Это анимированный комикс с движением камеры, карточками, переходами и субтитрами. Узнаваемость футболистов обеспечивают настоящие официальные фотопортреты; нарисованные дети — оригинальные вымышленные персонажи.

Сценарий: [ru.reel.yaml](ru.reel.yaml). Факты: [facts.json](facts.json). Источники: [sources.md](sources.md). Ревью: [review.yaml](review.yaml).

Изображения GPT Image и официальные фотопортреты находятся в игнорируемом shots/. Происхождение и контрольные суммы — в images.json. Видео и звук находятся в .reel/ru/. Это локальная версия для просмотра, без публикации и без редакционного одобрения владельца.

Копии для просмотра: `~/Downloads/inter-miami-magic-pass-ru/` — оригинал 213,3 МБ и облегчённый MP4 24,8 МБ, субтитры, обложка, раскадровка и манифест. [Кадры из готового MP4](preview/render-grid.jpg). [Технический отчёт](preview/QA.md): 13 проверок пройдены, пропусков нет. Проверены кадры всех сцен и детерминированная перемотка всех шести фотокарточек. `npm run check`: 107 тестов пройдены.

Речь проверена Whisper и фонемной моделью; это не заменяет субъективного прослушивания. Прослушивание человеком и редакционное одобрение ещё не зафиксированы.
