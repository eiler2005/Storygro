# Спартак и ЦСКА: секрет дерби

Объяснительный ролик для детей 10–12 лет, вертикальный формат для iPhone. Два вымышленных друга узнают историю московского дерби и решают футбольную задачу. Фотореалистичные изображения GPT Image, анимация камеры и титров; не видеосъёмка настоящего матча.

- [Ревью](review.yaml)

Звук: выбранный владельцем OmniVoice B, скорость 0,90. Изображения и медиа остаются в игнорируемых shots/ и .reel/. Версия для семейного просмотра; публикация не выполнялась.
