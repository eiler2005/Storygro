## Что не сделано и почему

- **Публикация и аналитика** (этапы 5–6) — нужны аккаунты владельца и выбор адаптера. Ничего не публикуется: `deliver`/`package` пишут локальные папки, `published: false`.
- **Публикация через API** — нет. Есть ручной журнал `storygro publish` и снимки `storygro metrics` ([publishing](../reference/publication-ledger.md)): человек загружает, журнал фиксирует.
- **Avatar / generated footage** (этап 4) — не подключались; запись экрана (`capture` + `screencast`) готова.
- **Профиль бренда** `content/brand.yaml` — черновик агента; владельцу нужно проверить аудиторию, голоса и список нежелательных фраз.
- **Короткая версия 20–40 с** — не делалась.
- **Живое прослушивание** — агент проверяет речь распознаванием и метриками, но не слышит интонацию и ударения. Владельцу нужно посмотреть и послушать ролики на телефоне.
- Qwen3 и проверка речи требуют Apple silicon; на другой машине проверка речи помечается как skipped.

## Важные уроки

- В YAML запятая внутри `{ text: a, b }` разрезает текст — теперь это ошибка с подсказкой; тексты с запятыми брать в кавычки.
- Qwen3 читает «ИИ» в начале фразы как одно «и», а «ВШЭ» как «ВШ»: использовать `[ИИ](=и-и)` внутри фразы, полную форму в начале, аббревиатуры расписывать.
- Изменение кода сцен после approve делает рендер устаревшим; `package` откажется — перерисовать после последней правки.
- Safe-zone в профилях — оценки по рекламным гайдам и сторонним замерам; проверить загрузку на телефоне.

### Что делать следующей LLM

1. Прочитать текущий выпуск и его REVIEW, открыть MP4; получить конкретный отзыв владельца на темп, стиль и голос. Не переизобретать название и исследование продукта.

## Новое обязательное правило: медиа вне публичного Git

По просьбе владельца видео, аудио, GIF, архивы, экспортные PDF/PPTX и веса моделей запрещены в Git. Любой файл — ≤1 МиБ; превью для документации/ревью — ≤300 КиБ. `.gitignore`, pre-commit и `npm run check`/CI проверяют это; не обходить через `git add -f`, LFS или переименование расширения. [Политика](../reference/media-policy.md).

Из текущего Git убраны 12 файлов (18 372 137 байт); локальные копии и резервная копия в игнорируемом `private/git-media-cleanup-2026-10-19/` сохранены. Воспроизводимые исходные картинки и Qwen WAV загружаются командой `npm run assets:fetch` по `content/media-assets.json`, с проверкой размера/SHA-256; различающиеся локальные оригиналы не перезаписываются. Установить локальный hook: `npm run hooks:install`.

Сценарии, факты, источники, лицензии и маленькие strip-превью остаются в Git. Исторические коммиты/теги не переписывались; старые blobs по-прежнему в истории. GitHub Releases находятся вне Git-истории и не увеличивают checkout; они остаются публичными. Исторический рендер micro1 не изменён: исходные файлы побайтно те же, меняется их хранение.

Проверки хранения: media guard, TypeScript и **24/24 теста pass**; в изолированной чистой папке восстановлены 6/6 исходников с совпадением SHA-256, повторный запуск использует кэш, изменённый локальный оригинал сохраняется и вызывает отказ. После той чистки в индексе было около 9,34 МиБ файлов вместо 26,84 МиБ. Для изменения хранения видеорендер не требовался: renderer/voice/scenes и содержимое исходных файлов не менялись.

Позднее при выборе Qwen для micro1 добавлено седьмое назначение в `content/media-assets.json`: `content/videos/micro1-work-data/assets/voice/narrator-ru.wav`, тот же публичный референс, что в историческом `ai-jobs`, с тем же SHA-256. `npm run assets:fetch` восстановил его без записи аудио в Git. Новый полный Qwen-рендер и его QA описаны выше; остальные русские выпуски не переключались. Сохранять выбранный владельцем C, не возвращать Dima только на основании ASR. - **Research-скан** (`production/src/sources.ts`, `sift.ts`, [ADR 0006](../adr/0006-research-scan.md), [подход](../explanation/research-approach.md)): HN за неделю, новые репозитории GitHub, статьи HF, русские Telegram-каналы (просмотры к медиане канала), RSS Habr, импорт X-дайджестов Grok (`--inbox`); `hype:` откладывает громкие заголовки, `block:` выбрасывает, совпадение ссылки в разных источниках поднимает в picks. Промпты: [Grok](../../production/trends/x-digest-prompt.md), [ракурсы](../../production/trends/angles-prompt.md). Скан 20.10 и 12 идей — [2026-10-20-scan.md](../../content/research/2026-10-20-scan.md), кандидаты в бэклоге.
- **Контент-процесс** ([объяснение](../explanation/content-workflow.md), [как одобрять](../how-to/review-and-approve.md)): `review.yaml` в папке выпуска — вопросы, заметки и три одобрения (сценарий → раскадровка → выпуск) с хешем того, что одобрено; одобрение раскадровки переехало из `.reel/approved.json` (старые файлы читаются). `storygro plan` пишет `PLAN.<variant>.md` + `preview/plan/` (кадр и картинки каждой сцены, текст, факты, вопросы). `storygro tracker` — [content/TRACKER.md](../../content/TRACKER.md) со списком «ждут тебя». Агент одобряет только технически (`--agent`); без терминала `approve` не запишет владельца.
- **Мультфильм** [agents-open-door](../../content/videos/agents-open-door/README.md): вертикальный, стиль `cartoon` с картинками 720×1280 (новое `images.width/height` в спеке), свои персонажи — волк Серый и заяц-робот Зайбот; реплика «Ну, обожди!» выбрана владельцем и используется только внутри ролика. Факты: Anthropic (первоисточник), Google через NBC, OpenAI через TechCrunch (пост OpenAI отдал 403), Replit через heise, эксперты CSO Online. Библия серии и 14 сюжетов с источниками — [open-door.md](../../content/series/open-door.md).
- Урок по кадрам: ключевой кадр сцены не показывает наложения в середине сцены — смотреть `still` через ~1 с после каждой метки. Длинные плашки (>27 знаков) в вертикали вылезают за края; заголовки сверху закрывают героев, поэтому в промптах «upper half empty wall».

Не сделано и ждёт владельца: одобрение сценария и выпуска «Открытой двери», ответы на вопросы в её `review.yaml`; озвучку целиком агент не прослушивал (проверены распознавание речи и громкость). Публикации нет.

## 21 октября: русские голоса, ударения, опись установленного

Запросы владельца: голос медленный, «замок» звучит как «зáмок», «OpenAI» коряво → «поищем модели, которые умеют на русском, включим в репо, чтобы был выбор; сравни качество и запиши выводы — далее будем использовать»; «запиши, что и где стоит на Mac и какого размера, чтобы я не удалил».

- **Проверка ударения без слуха**: фонемный распознаватель wav2vec2-xlsr-53-espeak-cv-ft различает замóк [zɐˈmok] и зáмок [ˈzamək] по редукции безударной гласной; эталоны Silero с явными `+` распознаются верно.
- **Стенд** `production/py/voice_bench.py` + `production/voices/bench-ru.yaml` (WER Whisper, ударения по фонемам в трёх дублях, бренды латиницей и кириллицей, UTMOS, слова/с, время синтеза) и страница прослушивания. Итоги и решение — [voices.md](../reference/voices.md#russian-voices-compared). Коротко: Qwen3 звучит лучше всех (UTMOS 4,32), но без пометок ошибается во всех омографах (0/12), с заглавной ударной — 9/12; Kokoro-RU 12/12 (тембр Димы владелец отверг); Chatterbox клонирует нашего рассказчика и слушается знака ударения, медленный; Silero — запасной.
- **Слой ударений** `production/py/stress.py` + `homographs-ru.txt`: ручные `+`/акут, RUAccent для списка омографов (и ё), вывод в журнал и в план; у каждого движка свой вид пометок (Qwen3 — заглавная гласная, Chatterbox — акут на каждом слове, Silero/Yandex — `+`). `voice.stress: auto | marks | off`. Ключ кэша русских строк включает версию слоя.
- **Движки**: `chatterbox` (`npm run setup:chatterbox`, отдельное окружение, рабочий процесс `-I`), `yandex` (REST v1, тест сборки запроса; **не запускался на живом API** — нет ключа).
- **Решение для новых русских выпусков**: Qwen3-рассказчик, `speed: 1.12`, `stress: auto`, бренды латиницей (кроме проверенных исключений вроде Replit); спорные омографы помечать вручную. Применено к «Открытой двери».
- **Опись** [local-setup.md](../reference/local-setup.md) и `npm run storage`: окружения ~4,6 ГБ, модели Storygro в кэше Hugging Face ~28 ГБ (весь кэш 38 ГБ — остальное от других инструментов), что нельзя удалять (`private/`, голосовые референсы, доставленные ролики).

Ошибки, исправленные по ходу: ранний вывод «заглавная гласная помогает Qwen» по одному примеру не подтвердился на четырёх seed для «замка», затем стенд на 12 дублях показал 9/12 против 0/12 — решение принято по стенду; `stress: off` в YAML 1.1 читается как `false` (теперь в кавычках); рабочий процесс Chatterbox импортировал собственный провайдер вместо пакета (запуск с `-I`); RUAccent падал на словах вне словаря («Оупен») — добавлены нулевые `token_type_ids`, как в kokoro-ru.
