## Подтверждённая задача

Первое применение — **собственные продукты и личный бренд владельца**. Следующая аудитория — другие авторы и разработчики, использующие ИИ-агентов.

Целевой цикл:

```text
Topic research → Sources → Brief → Script → Storyboard → Production
      ↑                                                ↓
Next experiment ← Analytics ← Publishing ← Review ← Content package
```

Начальные каналы: **Instagram и YouTube Shorts**. Начальные языки: **русский и английский**. Пользователь не ограничил продукт короткими роликами: объяснение может требовать 1–3 минут, а из него можно делать более короткие материалы.

Основной способ работы — человек ставит задачу обычным языком своему ИИ-агенту, а Storygro предоставляет агенту инструменты, шаблоны, правила и проверяемые артефакты. Сначала локальный CLI и документация для агентов; отдельный SaaS, аккаунты и сложный веб-редактор не нужны для первого результата.

## Форматы и приоритеты

| Формат | Роль |
|---|---|
| Animated explainer | Первый полноценный пример: объяснение идеи через сцены, метафоры и движение |
| Product demo | Демонстрация реальной функции собственного продукта |
| Tutorial | Запись экрана, выделение действий, пояснения и субтитры |
| Carousel | Самостоятельная последовательность карточек по материалам выпуска |
| Cover / still / social post | Обложка, изображения и тексты для публикации |
| Avatar / generated footage | Возможные дополнительные способы производства; не обязательны для первого примера |

Бумажная аппликация из референса Черняка — один художественный стиль. Сценарий должен объяснять механизм, сохранять предметы и персонажей между сценами и работать в полноценной вертикальной композиции.

## Примеры, предложенные для реализации

Это рабочие предложения ассистента, а не утверждённые владельцем сценарии:

1. **Explainer:** «Как из одной идеи получить видео, карусель и пост», 60–90 секунд, 9:16, RU и EN. Показывать только реально работающие на момент производства возможности Storygro.
2. **Product demo:** одна конкретная функция SlideCraft на реальном публичном примере.
3. **Tutorial:** воспроизводимый путь от исходной темы до готового материала с записью экрана.

Предыдущий вариант тестовой темы — «Как агент превращает задачу в готовый результат». Его можно использовать для технического пилота, если ещё рано демонстрировать весь процесс Storygro.

## Что ещё требует проверки, а не нового обсуждения названия

- Качество, стоимость и ограничения провайдеров озвучки RU/EN.
- Сравнение собственного рендера с HyperFrames на одинаковом примере.
- Возможности публикации и аналитики конкретных аккаунтов Instagram/YouTube.
- Бюджет платных генераций, если они понадобятся.
- Права на конкретные переносимые изображения, голоса, музыку и шрифты.
- Доступность доменов и иных имён: отдельная проверка не проводилась.

Решать технические вопросы последовательно по плану; не начинать исследование и выбор названия заново.
