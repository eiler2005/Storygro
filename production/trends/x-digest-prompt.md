# Промпт для Grok: недельный дайджест X

X не даёт бесплатного API, поэтому посты из X попадают в скан через Grok. Вставьте текст ниже в Grok (или в бота с доступом к поиску по X), сохраните ответ как `content/.signals/inbox/<дата>-x-<тема>.md` и запустите `trends` с `--inbox content/.signals/inbox`. Парсер читает нумерованные блоки со ссылкой `x.com/…/status/…`, строку счётчиков и строку «Суть:»; русские и английские названия счётчиков подходят. Закладки против лайков дают `saveRate`: пост, который сохраняют чаще, чем лайкают, обычно справочный, а не эмоциональный.

Тему и период меняйте под задачу. Списки исключений — та же логика, что `hype:` и `block:` в [`sources.yaml`](sources.yaml): громкий заголовок не равен полезному посту.

```text
Найди в X 15 самых полезных постов за последние 7 дней (с <дата> по <дата>) на тему:
<тема, например: практическая работа с ИИ-агентами, ИИ в видео и дизайне, внедрение ИИ в компаниях>.

Полезный = человек сохраняет пост, чтобы вернуться: конкретный приём, инструмент, репозиторий,
промпт, разбор исследования, честный опыт с цифрами. Ранжируй по числу закладок, а не лайков.

Отсекай:
- заголовки-кликбейт: insane, f*cking, mind-blowing, game changer, "X is dead", "RIP", "nobody is
  talking about", "you're not ready", 🤯, 🚨, BREAKING, "engineer at <компания> just…";
- посты, где главное — эмоция, а не содержание; угадай-что-внутри без ссылки;
- розыгрыши, «ретвитни и получи», продажу курсов, крипту, мемкоины, airdrop, NSFW;
- пересказы чужого поста без новой информации (бери оригинал);
- больше двух постов одного автора; агрегаторы «50 инструментов» — только если внутри есть
  конкретные ссылки с описанием.

Для каждого поста ровно такой формат, без вступлений между пунктами:

N. @handle
Ссылка: https://x.com/<handle>/status/<id>
Дата: ДД.ММ, ЧЧ:ММ PT | закладок: N | репостов: N | лайков: N
Суть: 1–2 предложения: что конкретно предлагается и чем полезно. Если в посте есть ссылка на
репозиторий, статью или статью arXiv — приведи её полностью.

Числа бери из поста как есть, не округляй. Если число недоступно, пропусти поле, не выдумывай.
```

Grok видит X лучше, чем наш скан, но остаётся моделью: ссылки и числа в ответе нужно открыть и проверить до использования. Дайджест — сигнал внимания, не доказательство тезиса.
